## Explicaciones detalladas

### Preguntas UD1 - XML

**1. b)** Los lenguajes de marcas son sistemas que combinan texto con etiquetas (marcas) que proporcionan información adicional sobre la estructura y semántica del contenido.

**2. b)** XML significa eXtensible Markup Language (Lenguaje de Marcas Extensible).

**3. b)** Los lenguajes de marcas se centran en describir y estructurar contenidos, mientras que los lenguajes de programación definen algoritmos y comportamientos.

**4. b)** SGML (Standard Generalized Markup Language) es el estándar del que deriva XML.

**5. c)** XML 1.0 es la versión estándar más utilizada, publicada en 1998 y con actualizaciones posteriores.

**6. b)** Un documento XML "bien formado" es aquel que cumple las reglas sintácticas básicas de XML.

**7. a)** La estructura de un documento XML consta de prólogo (declaración XML) y ejemplar (contenido con elementos).

**8. c)** Los comentarios en XML se escriben entre `<!-- y -->`.

**9. b)** Todo documento XML debe tener un único elemento raíz que contenga todos los demás elementos.

**10. c)** El atributo `standalone` indica si el documento depende de recursos externos (DTD, esquemas, etc.).

**11. a)** `&lt;` es la entidad predefinida que representa el símbolo menor que (<).

**12. b)** Los nombres de elementos XML NO pueden empezar con números, deben comenzar con letra o guión bajo.

### Preguntas UD2 - HTML

**13. a)** HTML significa HyperText Markup Language (Lenguaje de Marcas de Hipertexto).

**14. c)** Tim Berners-Lee creó el World Wide Web y el lenguaje HTML en 1991 en el CERN.

**15. b)** `<!DOCTYPE html>` es la declaración que define un documento HTML5.

**16. c)** La etiqueta `<title>` dentro de `<head>` define el título que aparece en la pestaña del navegador.

**17. c)** `<div>` es un contenedor genérico sin significado semántico, mientras que las otras son etiquetas semánticas de HTML5.

**18. b)** La etiqueta `<a>` (anchor) se utiliza para crear enlaces hipertexto.

**19. c)** El atributo `href` (hypertext reference) especifica la URL de destino del enlace.

**20. c)** La etiqueta `<img>` se utiliza para insertar imágenes en HTML.

**21. b)** El atributo `alt` es obligatorio por accesibilidad, proporciona texto alternativo para lectores de pantalla.

**22. a)** La etiqueta `<table>` define una tabla en HTML.

**23. b)** `<th>` (table header) define celdas de cabecera en tablas.

**24. b)** La etiqueta `<form>` crea un formulario HTML.

**25. b)** El atributo `action` especifica la URL donde se enviarán los datos del formulario.

**26. b)** `type="password"` hace que los caracteres se muestren como símbolos ocultos.

**27. d)** Tanto los checkboxes como `<select multiple>` permiten seleccionar múltiples opciones.

### Preguntas UD2 - CSS

**28. a)** CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada).

**29. b)** `<link rel="stylesheet" href="estilos.css">` es la forma correcta de vincular CSS externo.

**30. c)** Los selectores de ID tienen mayor especificidad que clases y etiquetas.

**31. c)** La propiedad `color` cambia el color del texto.

**32. d)** `margin` controla el espacio exterior entre elementos, `padding` el espacio interior.

**33. b)** `display: block` hace que un elemento se comporte como bloque (ocupa todo el ancho disponible).

**34. b)** Flexbox es un modelo de layout unidimensional (fila o columna).

**35. b)** `justify-content` alinea elementos en el eje principal (horizontalmente por defecto en Flexbox).

**36. b)** Las media queries (`@media`) permiten aplicar estilos según características del dispositivo.

**37. c)** La pseudo-clase `:hover` se activa cuando el cursor está sobre el elemento.

**38. b)** `<optgroup>` agrupa opciones relacionadas dentro de un `<select>`.

**39. b)** El atributo HTML5 `required` hace obligatorio un campo de formulario.

**40. c)** UTF-8 es la codificación estándar recomendada para documentos web y XML por su compatibilidad universal.

## Explicaciones de preguntas prácticas (41-55)

**41. b)** El elemento `<libro>` tiene 1 atributo: `isbn`. Los atributos se declaran dentro de la etiqueta de apertura.

**42. b)** La etiqueta `<ul>` (unordered list) crea una lista desordenada que se muestra con viñetas.

**43. b)** El atributo `target="_blank"` hace que el enlace se abra en una nueva pestaña o ventana del navegador.

**44. c)** Con `justify-content: space-between`, los elementos se distribuyen con espacio igual entre ellos (el primero al inicio, el último al final).

**45. b)** La tabla tiene 2 filas (`<tr>`): una fila de cabecera con `<th>` y una fila de datos con `<td>`.

**46. c)** El selector de etiqueta `h1` afecta a todos los elementos `<h1>` de la página, sin excepciones.

**47. b)** El atributo `type="email"` valida que se introduzca un formato de correo electrónico válido, y `required` lo hace obligatorio.

**48. d)** Ancho total = 200px (width) + 20px×2 (padding) + 5px×2 (border) = 250px. El margin no cuenta para el tamaño del elemento.

**49. b)** Si la imagen no carga, el navegador muestra el texto alternativo del atributo `alt` ("Logo de la empresa").

**50. c)** La media query `max-width: 768px` se aplica cuando el ancho de pantalla es menor o igual a 768px (tablets y móviles).

**51. b)** El elemento `<producto>` tiene 3 elementos hijos: `<nombre>`, `<precio>` y `<stock>`. El atributo `moneda` no es un elemento hijo.

**52. c)** La opción con el atributo `selected` (Italia) aparecerá seleccionada por defecto en el desplegable.

**53. c)** La pseudo-clase `:hover` se activa cuando el usuario pasa el cursor del ratón sobre el elemento.

**54. c)** Dentro del `<div>` hay 3 elementos: un `<h2>` y dos `<p>`. El `<div>` es el contenedor, no se cuenta a sí mismo.

**55. b)** El símbolo `#` indica un selector de ID, que es el más específico y solo debe aplicarse a un único elemento en la página.
