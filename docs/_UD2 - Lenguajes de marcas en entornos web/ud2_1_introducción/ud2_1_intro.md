
# UD2. Utilización de lenguajes de marcas en entornos web.

## Introducción

En esta unidad se estudiará la evolución del lenguaje HTML hasta el XHTML y las características básicas de los mismos, así como el uso de las hojas de estilos.

Es una unidad muy práctica y la más grande del módulo. En esta unidad volveremos a utilizar [Visual Studio Code]() a mano para ir probando todos los ejemplos y realizar modificaciones sobre los mismos, para así observar las variaciones en los resultados.

Al finalizar esta unidad de trabajo, se podrán elaborar páginas web sencillas.

## Contenidos

* HTML (*HyperText Markup Language*).  
* CSS (*Cascading Style Sheets*).
* Markdown
