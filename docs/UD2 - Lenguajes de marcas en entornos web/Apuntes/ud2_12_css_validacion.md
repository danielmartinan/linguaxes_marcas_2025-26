# Validación de CSS

La validación de CSS es el proceso de verificar que las hojas de estilo en cascada (CSS) cumplen con los estándares y especificaciones establecidos por el World Wide Web Consortium (W3C). La validación ayuda a asegurar que el código CSS es correcto, eficiente y compatible con diferentes navegadores y dispositivos.

Para ello, existen diferentes herramientas que nos facilitan este servicio:

- [W3C CSS Validation Service](https://jigsaw.w3.org/css-validator/)
- [Code Beautify CSS Validator](https://codebeautify.org/css-validator)

También podemos validar CSS directamente desde editores de código como Visual Studio Code, mediante extensiones como [CSS Lint](https://marketplace.visualstudio.com/items?itemName=stylelint.vscode-stylelint).
