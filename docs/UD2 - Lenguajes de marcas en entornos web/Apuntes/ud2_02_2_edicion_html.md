# Edición de HTML y CSS

Antes de seguir con la estructura y elementos de un documento HTML, es importante conocer las **herramientas** que permiten **editar** y **crear** documentos HTML y CSS. Al igual que XML, HTML es un lenguaje de texto plano, por lo que se puede editar con cualquier editor de texto. Sin embargo, es recomendable utilizar entornos de desarrollo que faciliten la edición y creación de documentos HTML.

:::note[Nota]
Revisa la seccion [Herramientas para la edición de documentos xml y html](../../UD1%20-%20Introducción/Apuntes/ud1_4_herramientas.md) donde se dan algunas recomendaciones de editores de texto y entornos de desarrollo, tanto para XML como para HTML.
:::

## VS Code

Ya hemos hablado de las ventajas que ofrece VS Code como editor de texto y entorno de desarrollo en la sección [Herramientas para la edición de documentos xml y html](../../UD1%20-%20Introducción/Apuntes/ud1_4_herramientas.md). Ahora vamos a profundizar en funcionalidades específicas para la edición de documentos HTML y CSS.

### Live Server

Permite lanzar un servidor local para previsualizar los cambios en el navegador en tiempo real. Cada vez que se guarda el documento, el navegador se actualiza automáticamente. De esta manera, podemos ver los cambios sin necesidad de recargar la página manualmente. Para utilizarlo, basta con hacer clic derecho en el archivo HTML y seleccionar "Open with Live Server". También podemos hacer clic en el icono de "Go Live" en la esquina inferior derecha de VS Code.

![live server click derecho](/img/linguaxes-marcas/ud2/img/live_server_right_click.png)

![live server go live](/img/linguaxes-marcas/ud2/img/live_server_go_live.png)

En ambos casos se abrirá el navegador con la página HTML y cualquier cambio que hagamos en el archivo se reflejará automáticamente en el navegador.
