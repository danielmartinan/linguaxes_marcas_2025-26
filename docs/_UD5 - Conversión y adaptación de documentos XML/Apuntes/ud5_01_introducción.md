# Unidad 5. Conversión y adaptación de documentos XML

## Resumen

Esta unidad sigue profundizando en el trabajo con documentos XML. Se estudiará XPath y XSLT. El primero permite extraer datos de un documento XML y, el segundo, permite generar ficheros XML o ficheros con formato (XHTML, PDF, etc.) a partir del contenido de uno o varios ficheros XML.

## Contenidos

- XPath.
- XSLT.

## Objetivos

- Identificar la necesidad de la conversión de documentos XML.
- Establecer ámbitos de aplicación.
- Analizar las tecnologías implicadas y su modo de funcionamiento.
- Describir la sintaxis específica utilizada en la conversión y adaptación de documentos XML.
- Crear especificaciones de conversión.
- Identificar las características de herramientas específicas relacionadas con la conversión de documentos XML.
- Realizar conversiones con distintos formatos de salida.
- Documentar y depurar las especificaciones de conversión.
